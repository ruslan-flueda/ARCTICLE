# arcticle

Статический сайт по макетам «Чистовик» и «Заглушка» из Figma. Верстка на HTML и CSS. На странице сервиса добавлена мини-игра на обычном JavaScript. Без библиотек и сборки.

## Файлы

- `index.html` — лендинг.
- `service.html` — страница «arcticle в разработке».
- `styles.css` — общие стили, секции и адаптация под планшет и телефон.
- `runner.js` — мини-игра с динозавриком на странице сервиса.
- `assets/images/` — изображения и SVG из Figma.
- `assets/fonts/` — шрифт Inter и его лицензия.

## Открыть сайт

Откройте `index.html` в браузере. Все материалы локальные: сайт работает без внешних запросов.

Обе кнопки на лендинге и пункт «Сервис» открывают `service.html`. Логотип и «О проекте» возвращают на главную.

## Мини-игра

Нажмите «Начать игру». Прыжок — пробел, стрелка вверх или касание игрового поля. Удерживайте стрелку вниз, чтобы пригнуться; в воздухе она ускоряет приземление. На телефоне есть отдельные кнопки: «Прыжок» и «Пригнуться» (удерживать). После столкновения нажмите «Ещё раз». Кнопка «Пауза» или Escape приостанавливает игру; переход на другую вкладку также ставит ее на паузу. Рекорд сохраняется в браузере, если доступно локальное хранилище.

За минуту скорость плавно удваивается, а интервалы между препятствиями сокращаются. После 10 секунд появляются птицы, после 18 — группы из трёх кактусов и разные размеры препятствий, затем открываются другие высоты полёта. Средние птицы требуют пригнуться или перепрыгнуть, низкие — перепрыгнуть, высокие можно пропустить стоя. Равнина, пустыня и горы сменяются каждые 18 секунд, день и ночь — в течение минутного цикла.

## Что осталось подключить

Поле почты сверстано, кнопка отправки отключена. Адреса не сохраняются. Для подписки замените блок `.email-form` в `service.html` на `<form>` с адресом выбранного обработчика и включите кнопку, изменив ее тип на `submit`. Это можно сделать без JavaScript. Уберите `role="group"` после замены на `form`.

Ссылки на [ВКонтакте](https://vk.ru/club242594706) и [Telegram](https://t.me/arcticleHSE) подключены в шапках обеих страниц и в подвале лендинга. Открываются в новой вкладке.

## GitHub Pages

1. Создайте репозиторий и загрузите в его корень содержимое этой папки: оба HTML-файла, `styles.css`, `runner.js`, `assets` и README.
2. В настройках репозитория откройте **Pages** и выберите публикацию из ветки с файлами сайта, папка **/ (root)**.
3. После публикации используйте выданный GitHub адрес.

Сборка не нужна. Относительные ссылки работают и в репозитории с собственным именем в адресе.

## Редактирование

Тексты меняются прямо в HTML. В начале CSS находятся основные цвета. Декоративные композиции имеют локальные координаты, остальные секции используют обычный поток страницы, Grid и Flexbox. Мобильная версия адаптирована из настольного макета: отдельного мобильного фрейма в Figma не было.
